# ARK OVERDRIVE

A small Android command-builder companion. It copies example commands to the clipboard; it does not execute them in ARK or provide cheats, game injection, ESP, aimbot, unauthorized teleportation, or anti-cheat bypass.

## Build on GitHub
1. Upload the contents of this folder to the root of your GitHub repository.
2. Open the repository's **Actions** tab.
3. Select **Build ARK OVERDRIVE APK** and press **Run workflow** (or push to `main`).
4. When the run finishes, open it and download the `ARK-OVERDRIVE-debug-apk` artifact.

The command syntax is illustrative. Verify compatibility with the exact ARK Mobile 2018 build and your server owner before use.
